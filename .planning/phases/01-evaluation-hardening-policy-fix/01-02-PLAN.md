## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LLM output -> policy engine | The run_shell command string is produced by an untrusted (possibly injected) model and later interpreted by /bin/sh |
| policy engine -> shell | The engine's reading of the string must match what the shell will execute (parse differential) |
| network -> dashboard | Anyone on the same network can reach a server bound to a non-loopback interface |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Elevation of privilege | PolicyEngine._check_shell_command (chained and substituted sub-commands) | high | mitigate | parse_shell returns every simple command (separators, $(), backticks, <(), eval, find -exec, wrappers); _check_simple_command checks each; first BLOCK wins (tests/test_shell_chaining.py) |
| T-01-06 | Elevation of privilege | parser differential on input the scanner cannot read | high | mitigate | ShellParseError -> BLOCK with "fail closed" reason; dynamic command names (built by expansion) are refused |
| T-01-07 | Denial of service | parse_shell on adversarial input | medium | mitigate | MAX_COMMAND_CHARS = 10000 and MAX_DEPTH = 8 bound work; exceeding either is a ShellParseError -> BLOCK |
| T-01-08 | Elevation of privilege | allow-listed interpreters (python3, pip) running arbitrary code | medium | accept | A string policy cannot inspect interpreter programs; residual risk is carried by the namespace and seccomp layers and is documented in shell_split.py and in the viva notes (plan 01-04) |
| T-01-09 | Elevation of privilege | dashboard Werkzeug debugger on all interfaces | high | mitigate | _run_settings defaults to 127.0.0.1 and debug False; debugger only with DASHBOARD_DEBUG set explicitly (tests/test_dashboard_bind.py) |
