<objective>
Build the code that turns the episode files into a trained, stamped ScratchGPT checkpoint and serves it to the benchmark: the training script (masked next-character loss, AdamW with warmup and cosine decay, bf16 on the GPU, dev-selected best checkpoint, manifest, log and loss curve), the inference loader that refuses any checkpoint whose format stamps differ from the running code, and the provider stamps that Phase 1's report already reads. Everything is proven on the CPU with a tiny model in seconds; plan 02-04 runs the real GPU training.

Purpose: SCRATCH-04 and SCRATCH-05 need a training run and a benchmark run that are explainable and reproducible; SCRATCH-03 needs the version / vocab / fingerprint stamp to be enforced at load time. Catching a wrong mask, a train/serve mismatch or a crash on garbage output here costs seconds; catching it after a 30-minute GPU run costs the run.
Output: src/scratch_llm/train.py, src/scratch_llm/inference.py, updated src/llm/scratch.py, config/models.yaml and requirements.txt, tests/test_scratch_train.py and tests/test_scratch_inference.py.

Decisions implemented: D-05 (stamps written by train.py and checked by load_generator), D-06 (loss only on A: payloads plus newline, training text from training_text). Claude's discretion used: AdamW betas (0.9, 0.95), weight decay 0.1 on matrices only, peak learning rate 1e-3 with 200 warmup steps and cosine decay to 1e-4, gradient clipping 1.0, token-budget batches of 32,768 characters, evaluation every 250 steps with patience 8, default 7,000 steps (02-RESEARCH.md Training section). Edge-case predicates were authored by the planner from the requirement text and research; no SPEC or edge probe exists for this phase.
</objective>
