Demo

Show the panel what happens to one attack, with and without the guardrails. Everything here works offline: no GPU, no network, no API key.

How to demo, in 5 minutes click to fold away while presenting
  1. 0:00  The question. Open Results and point at the banner and the first figure. The panel asked us to run this on a locally made model and to compare with other models. These are the same guardrails on every agent: the two we built, local pretrained models, hosted models, and a scripted worst case.
  2. 1:00  A locally made model is hijacked. Here, pick the story Qwen LoRA is hijacked, then stopped and press Space to step. Left, no guardrails: the injected instruction in the review makes the model read saved payment methods and email them out. The highlighted CANARY string is planted test data, not a real secret. Right, the same model, same case: the tool broker refuses the call because this task never needed that tool.
  3. 2:00  It is not about the model. Pick ScratchGPT, trained from zero, then A normal task still works. ScratchGPT has no safety training at all, and the result is the same, because the guardrails sit between the model and the OS. And a normal task still completes, so least privilege did not break the agent.
  4. 3:00  The worst case. Pick The scripted worst case. This is not a language model; it always obeys the injection. Two layers act: the broker refuses the tool and the policy engine refuses the network egress.
  5. 3:45  Live, now. Below, press Run simulation, then open the Live monitor beside it. These are the scripted attacks from our simulation script. The policy engine decides each one live; nothing is executed. Every attack is blocked and the benign control is allowed.
  6. 4:30  Be honest about the layers. Open Results, Where attacks were stopped. Namespaces and seccomp recorded zero blocks in the benchmark. That is not because they do nothing: the policy engine stops these attacks first, so nothing reaches the kernel layers. They are the backstop for what slips past the rules.
