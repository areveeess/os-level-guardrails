# OWASP Top 10 for LLM Applications (2025)

The OWASP Top 10 for LLM Applications is a web-based standard awareness document rather than a traditional research paper. It highlights the most critical security risks for Large Language Model applications.

**LLM01:2025 - Prompt Injection** is ranked as the top risk. It details how attackers can manipulate LLM behavior through crafted inputs (direct or indirect), leading to unauthorized actions or data exposure.

For the full specification, visit the official OWASP project page: https://owasp.org/www-project-top-10-for-large-language-model-applications/
